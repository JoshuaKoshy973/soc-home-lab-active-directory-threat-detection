# Printer Support Lab Screenshots

Screenshots are added as evidence is captured during the lab. Each filename identifies the result being demonstrated and is referenced from the relevant setup, incident, or runbook page.

## Evidence groups

- `01`–`08`: baseline, print-server setup, queues, sharing, access control, and client connection
- `09`–`10`: single-user access failure and restoration
- `11`–`13`: Print Spooler outage, offline symptom, and recovery
- `14`: plotter connectivity diagnostic failure
- `16`–`17`: Jira ticket intake and resolution history

The numbering intentionally follows the evidence captured during the lab; filenames are kept stable so documentation links remain reliable.
